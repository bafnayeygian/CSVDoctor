# CSVDoctor

Profile CSV files and detect missing values, duplicate rows, type inconsistencies, and column quality issues.

Version: **1.0.0**

## Installation

```bash
git clone https://github.com/bafnayeygian/CSVDoctor.git
cd CSVDoctor
python -m pip install .
```

## Usage

```bash
csv-doctor --help
```

## Development

```bash
python -m unittest discover -s tests -v
python -m compileall -q src
```
